# DSA Class Questions

This repository contains the Data Structures and Algorithms questions and problems that I have practiced during my classes.

All solutions are implemented in **Java** and organized week-wise for easy reference.

## Topics Covered

* Object-Oriented Programming
* Exception Handling
* Arrays
* ArrayList
* Sliding Window
* Two Pointer Technique
* Searching
* Sorting
* Recursion
* Backtracking
* Singly Linked List
* Doubly Linked List
* Circular Linked List
* Dynamic Programming
* HashSet
* Binary Search
